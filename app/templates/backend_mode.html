"Detect this machine's IP" only gives a correct answer when run from the LAN laptop's own copy of this page -- open http://localhost:<port>/admin/backend-mode directly on that laptop and click it there. It fills in and copies the right value so you don't need to run ipconfig/ifconfig yourself. Clicking it here on the cloud dashboard (or any machine other than the actual LAN host) would just detect THIS machine's own network address, which isn't what you want -- there's no way for the cloud deployment to see a laptop on your venue's WiFi from here, so getting the real value onto this page still means pasting it in from wherever you detected it.

Saving sends this browser straight to whichever dashboard is now the active one (the LAN server's if you just switched to LAN, or back to this cloud deployment if you switched back) -- that's the one that actually shows live rounds/players from here on, since each server has its own separate database. Because that's a different site, your login session won't carry over: you'll need to enter that server's admin PIN again once you land there.

Changing this mid-round will not migrate players already connected to the old backend mid-round -- treat it as a between-rounds decision, not something to flip while people are mid-investigation.
